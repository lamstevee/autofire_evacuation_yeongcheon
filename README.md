# 영천 산불 재난 대피 시뮬레이터

경북 영천을 배경으로, 산불 위험 단계에 따라 **자율주행 셔틀과 구급차를 배치하고 주민을 대피시키는 과정을 지도에서 시연**하는 웹 프로젝트입니다.

현재 구현은 **미리 생성한 JSON을 재생하는 프런트엔드 프로토타입**입니다. 실제 산불·기상·주민정보 API, 차량 제어, 현장 단말 전송, OR-Tools 최적화는 연결되어 있지 않습니다. 화면의 관련 로그는 시나리오 설명용 문구입니다.

## 무엇을 볼 수 있나요?

- 평시 운행 → 선제 재배치 → 거점 대기 → 대피 실행의 4단계
- 차량 이동, 주민 분포, 화재 영역, 거점·대피소 지도 표시
- 단계 수동 선택, 재생·일시정지, 1·5·10배속
- 차량별 임무, 주민 A/B 그룹 진행률, 시뮬레이션 완료 예상 시간
- 화재 영역·경로·차량·주민·시설 레이어 켜기/끄기

화재 영역은 단계별로 저장된 도형이며, 도로망이나 실제 산불 확산을 계산하는 모델은 아닙니다. 주민 좌표와 배차는 생성 스크립트가 만든 가상 데이터입니다.

## 실행

Node.js 20.9 이상과 npm이 필요합니다. 이번 검토는 Node.js 24.15.0에서 진행했습니다.

```sh
cd frontend
npm ci
npm run dev
```

**http://localhost:3000**에 접속한 뒤 시나리오와 단계를 고르고 재생 버튼을 누릅니다. 단계 전환은 자동이 아니라 사용자 조작 방식입니다. Windows PowerShell에서 실행 정책 오류가 나면 `npm.cmd`를 사용하세요.

```sh
# frontend 폴더에서
npm run build
npm start
npm run lint
```

별도 API 키나 데이터베이스는 필요하지 않습니다. 지도는 외부 CARTO 지도 스타일·타일을 사용하므로 네트워크 연결이 필요하며, 빌드는 `next/font/google`을 통해 폰트를 가져옵니다.

## 시나리오

| 시나리오 | 풍속 | 주민 A/B | 셔틀 | 구급차 |
| --- | --- | --- | --- | --- |
| S1 표준 | 10m/s | 3 / 30명 | 3대 | 2대 |
| S2 강풍 | 18m/s | 6 / 60명 | 3대 | 3대 |
| S3 증차 | 18m/s | 10 / 100명 | 10대 | 5대 |

값은 `frontend/public/data/scenario_manifest.json` 기준입니다. A는 구급차, B는 셔틀에 배정됩니다. S2와 S3는 주민 수도 다르므로 차량 증차 효과만 분리한 비교 실험으로 해석하면 안 됩니다. 설명에 있는 골든타임 달성 여부를 별도로 계산·검증하는 기능은 없습니다.

## 코드 구조

```text
frontend/src/app/                 Next.js 페이지·레이아웃·스타일
frontend/src/components/
  MapComponent.tsx               지도·차량 애니메이션·픽업 판정
  LeftPanel.tsx                  시나리오·단계·배속·진행률
  RightPanel.tsx                 차량별 임무·진행 상황
  TopHeader.tsx                  단계와 상황 안내 문구
  LogFeed.tsx                    이벤트 로그
frontend/src/store/              Zustand 상태·시나리오 로딩·예상 시간
frontend/public/data/            S1~S3 JSON·목록·호환용 mock
scripts/generate_mock.py         가상 주민·차량·경로 생성
docs/CODE_REVIEW.md              코드리뷰 및 검증 결과
```

기술 구성은 Next.js 16, React 19, TypeScript, Tailwind CSS 4, Zustand, MapLibre GL 및 react-map-gl입니다. 데이터 흐름은 `JSON → Zustand → 지도와 패널`이며, 브라우저의 애니메이션 프레임마다 차량 위치를 갱신합니다.

## 데이터 재생성

Python 3와 표준 라이브러리만 사용합니다. 출력 경로가 작업 디렉터리 기준이므로 **반드시 `scripts` 폴더에서 실행**하세요.

```sh
cd scripts
python generate_mock.py
```

기존 시나리오 JSON과 manifest를 덮어씁니다. 생성기는 `random.seed(hash(params.id))`를 사용해 Python 프로세스가 달라지면 같은 시나리오도 달라질 수 있습니다. 재현 가능한 비교에는 현재 커밋된 JSON을 그대로 사용하세요.

## 현재 상태와 제한사항

2026-11-17 검토에서 프로덕션 빌드와 TypeScript 검사는 통과했습니다. `npm run lint`는 **오류 1개·경고 3개로 실패**했습니다. 자동 테스트 명령은 아직 없습니다.

현재는 주민 근처에서 픽업 처리되는 즉시 대피 완료로 집계합니다. 따라서 진행률 100%가 대피소 도착을 뜻하지 않습니다. 예상 완료 시간도 실제 이동 시간이나 안전성을 판단하는 지표가 아닌 애니메이션 기준 추정치입니다. 리셋과 시나리오 연속 전환에도 개선할 부분이 있습니다.

구체적인 근거와 수정 방향은 [코드리뷰](docs/CODE_REVIEW.md)를 참고하세요. 이번 변경은 문서화이며 발견된 동작 문제는 아직 수정하지 않았습니다.
